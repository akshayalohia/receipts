# Breakout rules

Good leads are personal wins someone would put on a shelf:
- A post far above the author's normal (>= 20x their median likes), or >= 1k likes on a small account (< 5k followers).
- Milestones: subscribers (1k, 10k, 50k), GitHub stars (1k, 10k), first sale, MRR, funding, new job, promotion, launch day, hackathon win, Product Hunt top 5, Show HN front page.

Drop (the tools may still store them; tell the designer by not posting them as highlights):
- Brands and large media accounts, giveaways, crypto shilling, politics, tragedy, outrage, anything about minors.
- Reposts of someone else's win.
